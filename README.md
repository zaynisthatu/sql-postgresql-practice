# sql-postgresql-practice

SQL practice on PostgreSQL covering filtering and sorting, joins, self joins, subqueries and aggregation. It holds 23 queries over one small relational schema, the recorded output of every query, and a log of the errors met along the way with PostgreSQL's messages and the corrected queries.

The practice took place in August 2025 in pgAdmin on a local PostgreSQL install. All queries were re-run on PostgreSQL 16 for this repository.

## Contents

| File | Topic |
|---|---|
| `schema.sql` | Practice database: customers, payments, employees, departments and a family tree. All data is made up. |
| `queries/01_select_filter_sort.sql` | SELECT, WHERE, IN, LIKE, BETWEEN, ORDER BY, LIMIT, DISTINCT |
| `queries/02_joins.sql` | INNER JOIN, LEFT JOIN |
| `queries/03_self_join.sql` | Self joins (family tree, employee and manager) |
| `queries/04_subqueries.sql` | Scalar, IN, correlated and NOT EXISTS subqueries |
| `queries/05_aggregates_group_by_having.sql` | COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING |
| `results/` | Output of every query, generated by running the files on PostgreSQL 16 |
| `errors_and_fixes.md` | Errors met during practice, with PostgreSQL's error message and the corrected query |
| `run_all.sh` | Creates a database, loads the schema and runs every query file |

## Schema

Five tables: `customer` and `payment` (each payment references a customer), `employees` and `departments` (each employee references a department and a manager), and `family` (each row references its parent).

## Run it

```bash
./run_all.sh            # needs a running PostgreSQL and psql
```

`run_all.sh` takes an optional database name (default `practice`).
